O que é phishing?

Phishing é um golpe em que alguém finge ser uma empresa, banco ou pessoa confiável — por e-mail, SMS, WhatsApp ou rede social — para te convencer a clicar num link e digitar senha, CPF ou dados de cartão numa página falsa.

O nome vem de "fishing" (pescar): o golpista lança uma isca (a mensagem urgente, a promoção boa demais) esperando que alguém morda.

Como ler uma URL

Leia sempre da direita para a esquerda, até achar a primeira barra "/". O que vem logo antes dela é o domínio de verdade — o resto é decoração.

  • itau.com.br/login → domínio real: itau.com.br
  • itau.seguranca-cliente.top/login → domínio real: seguranca-cliente.top (não é o Itaú)
  • www.itau.com.br@evil.example/login → domínio real: evil.example (tudo antes do "@" é ignorado)

Sinais de alerta

  • Urgência ("sua conta será bloqueada em 24h")
  • Pedido de senha, código de confirmação ou dados de cartão por link
  • Domínio parecido, mas não idêntico ao oficial
  • Link encurtado escondendo o destino real
  • Extensão de domínio incomum (.xyz, .top, .click)
  • Erros de português ou formatação estranha na mensagem

Cliquei num link suspeito. E agora?

  1. Não digite mais nada na página — feche a aba.
  2. Se digitou senha, troque-a agora no site oficial (digitado à mão, não pelo link).
  3. Ative a verificação em duas etapas nas contas importantes.
  4. Se informou dados de cartão, ligue para o banco e peça o bloqueio/reemissão.
  5. Avise quem te enviou o link — a conta dessa pessoa pode estar comprometida.
